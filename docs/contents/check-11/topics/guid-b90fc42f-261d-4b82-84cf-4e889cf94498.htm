Inserting a table within a table generates no output at all. According to research, this is bad information architect and isn't technically allowed by DITA. There are workarounds, primary what we already do by inserting a paragraph tag inside a cell, then inserting a table inside the paragraph. You can create that, but the FMPS won't generate an output for it. We need to eliminate tables within tables in our DITA content.

Copy and pasting from Excel creates a simple table (see the next table). I'm not sure what the difference between simple tables and regular tables is. Simpletables cannot have a table title, and are typically only for simple, column data. I think you can still merge cells, though.
