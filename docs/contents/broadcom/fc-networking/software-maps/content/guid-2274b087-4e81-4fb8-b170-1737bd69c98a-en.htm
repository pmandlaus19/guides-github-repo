Temperature Sensor

The Temperature Sensor object type allows you to monitor the temperature of the system.

On Brocade Gen 8 platforms running Fabric OS v10.0.x, individual sensor-based temperature monitoring has been deprecated. MAPS temperature monitoring capabilities have been enhanced to monitor the ambient temperature.

The following table lists the predefined groups monitored by the Temperature Sensor object type.

Predefined Groups for the Temperature Sensor Object Type

Predefined Group Name
Description

ALL_TS

All temperature sensors in the system.

The following example displays the predefined groups in the ALL_TS object type:switch:admin> logicalgroup --show ALL_TS

Resolve the ambient temperature alerts first if both ambient and system temperature warnings are triggered. Resolving the ambient temperature can mitigate the system temperature issue, as high ambient temperatures can cause system temperatures to rise. Ensure that the following actions are taken for the effective management of the system and ambient temperature:
