Firmware Upgrade Considerations for MAPS

Consider the following information before upgrading a device to Fabric OS v10.0.x:
  • The Rule Quiet Time and Global Quiet Time configurations from the pre-Fabric OS v10.0.x release are supported in the default notification mode with a warning message. When you enable the adaptive notification feature, the Rule Quiet Time and Global Quiet Time configurations are no longer supported and are available only in the default notification mode.
  • Custom SFP groups that are created in pre-Fabric OS v10.0.x releases are not supported in the Fabric OS v10.0.x release. Ensure that the custom SFP groups are deleted using the logicalGroup --delete <Custom SFP Group Name> command before upgrading.
  • Custom Circuit groups that are created in pre-Fabric OS v10.0.x releases are not supported in the Fabric OS v10.0.x release. Ensure that the custom Circuit groups are deleted using the logicalGroup --delete <Custom Circuit Group Name> command before upgrading.
  • If you have any paused SFP objects, the upgrade to Fabric OS v10.0.x is blocked. Ensure that the paused SFP object is restarted using the mapsConfig --config restart -type sfp -members <Paused Member list> command.
  • If you have augmented any groups except HOST, TARGET, and ALL_OTHER_F_PORTS in the pre-Fabric OS v10.0.x release, the upgrade to Fabric OS v10.0.x is blocked. Ensure that the group memberships are restored using the logicalGroup --restore <Group Name> command before upgrading.
  • If you have added pre-defined rules for FCoE SFP monitoring in a custom policy, ensure that these rules are not monitored in Fabric OS v10.0.x. Ensure that these rules are removed before upgrading.
  • If you have enabled secure SMTP without importing the SMTPS CA certificate, the upgrade to Fabric OS v10.0.x is blocked. Ensure that the SMTPS CA certificate is imported before upgrading.
  • If you have configured the TLSv1 protocol for secure SMTP in pre-Fabric OS v10.0.x releases, the upgrade to Fabric OS v10.0.x is blocked.
  • Fabric OS v10.0.x does not support pre-defined FCoE SFP monitoring rules that are created in custom MAPS policies on pre-Fabric OS v10.0.x releases. These rules must be deleted before upgrading.
  • If you have created any custom groups for SFP and CIRCUIT members, the upgrade to Fabric OS v10.0.x is blocked.
