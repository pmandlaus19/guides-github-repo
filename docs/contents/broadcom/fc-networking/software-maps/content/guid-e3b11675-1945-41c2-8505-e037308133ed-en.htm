Configuring the Relay Host Server

In MAPS, the relay host server, typically an SMTP server, acts as an intermediary for sending Email notifications.

The relay host server receives Email alerts from the MAPS configuration on the switch and relays them to the specified recipient email addresses. It handles the relaying of email messages between the switch and recipient email addresses.

A Mail Transfer Agent (MTA) handles the routing and transfer of emails between mail servers. When you send an email, the MTA is responsible for ensuring that it reaches the intended mailbox of the recipient. MTAs use the Simple Mail Transfer Protocol (SMTP) to communicate and transfer emails between servers. You can use the relayconfig command to configure the SMTP server. MAPS email delivery uses the configured relay server information for relaying emails to the configured recipient address.

To specify the relay host server, complete the following steps.
  1. Connect to the switch and log in using an account with admin permissions.
  2. Enter relayconfig --config -rla_ip <relay IP address> -rla_dname <relay domain name>.

The following example shows the relay host address and relay domain name for the switch.

switch:admin> relayconfig --show
Relay Host:                     192.168.0.0
Relay Domain Name:              relay_smtp.test.com
Secure SMTP:                    Enabled












































Secure SMTP, the SMTPS protocol, is a feature that provides secure email transmission for MAPS notifications. It enhances email security by using TLS encryption and authentication when sending emails from the switch to a specified mail relay server. This protocol ensures confidentiality and integrity of the email messages during transit. The relayConfig command with the -secure_smtp option to enable or disable the secure SMTP is shown in the following command options:

relayConfig --config -rla_ip <relay IP> -rla_dname <domain name>
relayConfig --config -secure_smtp {true|false}
relayConfig --config -rla_ip <relay IP> -rla_dname <domain name> -secure_smtp {true|false}





























Note: In Fabric OS v10.0.x, importing the SMTP server CA certificates is mandatory to enable for enabling a secure SMTP configuration.

If you have not configured the relay host configuration (relayConfig) settings in the pre-Fabric OS v10.0.x releases and are configuring the relay host for the first time, Secure SMTP is enabled by default as described in the following example:

switch:admin> relayConfig --config -rla_ip 192.168.0.0 -rla_dname relay.smtp.company.com

2025/07/02-09:06:35 (PST), [MAPS-1017], 377, FID 128, INFO, cassian6, MAPS relayConfig got updated to relay_IP: 192.168.0.0, domain: relay.smtp.company.com, secure SMTP mode: Enabled.
 












































Note: When secure SMTP mode is enabled, the switch establishes a connection with the SMTP server on default port 587 for TLS. When secure SMTP is disabled, the default SMTP port 25 is used in a non-secure mode.
Perform the following preparatory tasks before configuring a secure SMTP protocol:
  • Import SMTP server CA certificates (mandatory)
  • Configure the Cipher Suite
For more information on the preceding tasks, refer to the Brocade Fabric OS Administrators User Guide.You can configure secure SMTP in two ways:
  • Manual Configuration: Configure using either both relay IP/domain and secure SMTP, or only secure SMTP
  • Default Configuration (Fresh Installation): Secure SMTP is configured by default during a fresh installation when either:
    • Configuring Email action for the first time
    • Configuring a relay IP/domain name for the first time

The following sections explain how to configure secure SMTP using both of the methods discussed above.

You can manually configure the secure SMTP using both relay IP/domain and secure SMTP as shown in the following example:switch:admin> relayConfig --config -rla_ip 1.2.3.4 -rla_dname broadcom.com -secure_smtp true

2025/08/07-04:24:32 (GMT), [MAPS-1017], 9724, FID 128, INFO, goose86, MAPS relayConfig got updated to relay_IP: 1.2.3.4, domain: broadcom.com, secure SMTP mode: Enabled.





























switch:admin> relayconfig --show
Relay Host:                     1.2.3.4
Relay Domain Name:              broadcom.com
Secure SMTP:                    Enabled
 



























































You can manually configure using only secure SMTP as described in the following example:switch:admin> relayConfig --config -secure_smtp true

2025/08/07-04:25:31 (GMT), [MAPS-1019], 9726, FID 128, INFO, switch, MAPS secure SMTP mode is Enabled.
 












































switch:admin> relayconfig --show
Relay Host:                    
Relay Domain Name:              
Secure SMTP:                    Enabled
 



























































The following error appears when configuring with either both relay IP/domain and secure SMTP, or with only secure SMTP without importing SMTP server CA certificates:secure SMTP is being configured and SMTPS CA certificate is not imported, Kindly import before enabling secure SMTP mode.

2025/08/07-06:42:11 (GMT), [MAPS-1130], 3, FID 128, INFO, goose86, Actions email configured.



























































switch:admin> relayconfig --show
Relay Host:
