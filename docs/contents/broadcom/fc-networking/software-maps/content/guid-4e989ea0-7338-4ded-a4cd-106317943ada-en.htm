Gigabit Ethernet Ports

The Gigabit Ethernet (GE) Ports object type monitors statistics for GE ports and GE SFPs on Brocade Extension platforms.

Starting from Fabric OS v10.0.x, MAPS has been enhanced to dynamically monitor threshold values for GE SFP parameters directly from vendor-programmed SFP modules. This functionality allows MAPS to read the actual threshold value configured by the vendor for a specific SFP module, rather than relying on static threshold values defined within MAPS rules. This helps to avoid the manual configuration of static GE SFP thresholds in MAPS rules and the creation of new logical groups for each type of GE SFP.

The following statistics are used to monitor the Ethernet SFP modules:

  • CURRENT
  • GE_CRC
  • GE_LOS_OF_SIG
  • VOLTAGE
  • RXP
  • SFP_TEMP
  • TXP
