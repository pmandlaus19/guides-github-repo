LAG

The LAG object type allows you to monitor the link aggregation groups (LAGs) present in IPS LS. A LAG is a group of physical Ethernet links that are treated as a single logical link.

The following table lists the predefined groups monitored by the LAG object type.

Predefined Groups for the LAG Object Type

Predefined Group Name
Description
ALL_LAGS
At the LAG level, MAPS monitors and aggregates the throughput of the group members to report as a single tunnel or port. Using MAPS, only the ethernet LAGS that are online are monitored, and early warnings are issued if throughput exceeds.
The following example shows a predefined group with the specific list of ALL_LAG group members monitored by the MAPS.switch:admin> logicalgroup --show ALL_LAGS
