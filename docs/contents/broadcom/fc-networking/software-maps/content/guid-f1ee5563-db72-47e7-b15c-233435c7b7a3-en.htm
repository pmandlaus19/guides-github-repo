Extension Gigabit Ethernet Port Health

The Extension Gigabit Ethernet (GE) Port Health category monitors the Gigabit Ethernet port statistics and takes action based on the configured thresholds and actions. You can configure thresholds and apply the configuration to all ports.

Extension GE Port Health Category Parameters

Monitoring System

Description

GE_CRC

Describes the number of times an invalid cyclic redundancy check (CRC) error occurs on a Gigabit Ethernet port, or a frame computes an invalid CRC. Invalid CRCs can represent noise on the network. Such frames are recoverable by retransmission. Invalid CRCs can indicate a potential hardware problem.

GE_LOS_OF_SIG

Describes the number of times that signal loss occurs in offline Gigabit Ethernet ports. Signal loss indicates that no data is moving through the port. A loss of signal usually means a hardware problem.

CURRENT

Describes the amperage that is supplied to the Extension Gigabit Ethernet port in milliamperes (mA). Alerts on current metric indicate potential hardware failures.

RXP

Describes the power of the incoming laser (receive power) in microwatts (μW). This value is used to help determine if the Extension Gigabit Ethernet port is in good working condition. If the value is lower or greater than the threshold, there is a potential problem with an Extension Gigabit Ethernet port.

TXP
Describes the power of the outgoing laser (transmit power) in microwatts (μW). This value is used to determine if the Extension Gigabit Ethernet port is in good working condition. If the value is lower or greater than the threshold, there is a potential problem with an Extension Gigabit Ethernet port.
VOLTAGE
Describes the voltage that is supplied to the Extension Gigabit Ethernet port in millivolts (mV). If this value exceeds the threshold, the Extension Gigabit Ethernet port is deteriorating.
SFP_TEMP
Describes the temperature of the Extension Gigabit Ethernet port in degrees Celsius. High temperatures indicate that the Extension Gigabit Ethernet port could be in danger of damage.

Rule Data

The following example shows one of the default rules for monitoring the Extension Gigabit Ethernet port health. This rule triggers the configured actions when the number of GE_CRC errors exceeds the threshold.

Rule Data:
----------
RuleName: defALL_EXT_GE_PORTSCRC_1
Condition: ALL_EXT_GE_PORTS(GE_CRC/MIN>1)
Actions: RASLOG,SNMP
Associated Policies: dflt_moderate_policy, dflt_conservative_policy










































































RASLog Example

The following example shows the RASLog message that is generated when the GE_CRC error occurs.

2025/07/11-10:09:03 (GMT), [MAPS-2062], 105, FID 128 | PORT 0/GE6, WARNING, AWING_157-49-10, GE Port ge6, Condition=ALL_EXT_GE_PORTS(GE_CRC/min>1), Current Value:[GE_CRC, 50 CRCs], RuleName=defALL_EXT_GE_PORTSCRC_1, Dashboard Category=Extension GE Port Health, Quiet Time=None.
