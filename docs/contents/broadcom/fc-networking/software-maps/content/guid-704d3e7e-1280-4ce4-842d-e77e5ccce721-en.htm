Fan

The Fan object type allows you to monitor the state of fans. The FAN_STATE monitoring system is used to monitor the fans.

The following table lists the predefined groups monitored by the Fan object type.

Predefined Groups for the Fan Object Type

Predefined Group Name
Object Type
Description
ALL_FAN
Fan
All fans in the chassis.

The following example displays the predefined group with the specific list of ALL_FAN group members monitored by the MAPS.switch:admin> logicalgroup --show ALL_FAN

--------------------------------------------------------------------------------------------------------------
