Email Alerts

An email alert action sends information about the event to one or more specified email addresses. The email alert specifies the threshold and describes the event, much like an error message.

To configure the email recipients, use the mapsConfig --emailcfg interactive command. Multiple destination email addresses are possible. The addresses must be separated using a comma between each address, and each address must be a complete email address. For example, abc@company.com is a valid email address; abc@company is not.

To clear all configured email addresses, enter the following command. All configured email addresses are erased.

switch:admin> mapsConfig --emailcfg
Enter the email address(es) : none
Enter the from address : none
