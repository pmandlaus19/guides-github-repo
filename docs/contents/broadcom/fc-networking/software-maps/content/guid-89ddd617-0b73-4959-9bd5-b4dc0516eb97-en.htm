Group

A MAPS group is a collection of similar objects that helps administrators to monitor multiple MAPS objects as a single entity.

You can create a group of objects and then use that group in rules, thus simplifying rule configuration and management. For example, you can create a group of ports that are connected to Windows servers, and then create specific rules for monitoring this group. Each object can be a member of multiple groups. Multiple rules can use the same group. A group is also referred to as a logical group.

MAPS allows you to collectively view information for all logical groups or view information for a specific group. To view a summary of all logical groups on a switch, enter the logicalgroup --show command. Use this command for group management and to view information about each group. The command output presents a table that lists the following characteristics for each group:
  • The name of the group
  • Whether the group is a predefined group or not
  • The type of items in the group [port, Small Form-factor Pluggable (SFP), power supply, and so on]
  • The number of members associated with the logical group
  • A list of current members
