Chassis

The Chassis object group type allows you to monitor the chassis systems. You can use the following monitoring systems to monitor the chassis systems:
  • ASC_UPLOAD_FAILURE
  • BAD_TEMP
  • CPU
  • BAD_FAN
  • BAD_PWR
  • DAYS_TO_EXPIRE
  • DOWN_CORE
  • EXPIRED_CERTS
  • ETH_MGMT_PORT_STATE
  • FAN_AIR_FLOW_MISMATCH
    Note:

    The default rules, defCHASSISETH_MGMT_PORT_STATE_UP and defCHASSISETH_MGMT_PORT_STATE_DOWN, are deprecated on Brocade Gen 7 platforms running Fabric OS 10.0.x. Their association with default policies has been discontinued. These rules are deprecated and will be removed in a future release.

    The default rules defCHASSISETH_MGMT_PORT_STATE_UP and defCHASSISETH_MGMT_PORT_STATE_DOWN are not supported on Gen 8 platforms.

    The rules defALL_SLOTSETH_MGMT_PORT_STATE_UP and defALL_SLOTSETH_MGMT_PORT_STATE_DOWN monitor the state change of Ethernet Management ports on both active and standby CPs. These rules are supported on Gen 7 and Gen 8 platforms and associated with the system policy, that is, dflt_always_active_policy.

  • FAULTY_BLADE
  • FLASH_USAGE
  • HA_SYNC
  • IT_RES_USAGE
  • ITL_RES_USAGE
  • MEMORY_USAGE
  • MEMORY_USAGE_STATE
  • SYSTEM_TEMP
  • TRUFOS_CERT_DAYS_TO_EXPIRE
  • TRUFOS_CERT_EXPIRED
  • TRUFOS_CERT_INSTALLED
  • WWN_DOWN
  • ZONE_CFGSZ_PER

The following table lists the predefined group that is monitored by the CHASSIS object type.

Predefined Groups for the Switch Object Type

Predefined Group Name
Description
CHASSIS
Default group used for defining rules on parameters that are global for the whole chassis, for example, CPU or flash.
