Firmware Downgrade Considerations for MAPS

Consider the following items when you downgrade from the Fabric OS v10.0.x release:
  • Ensure that all the IPS configurations are removed before downgrading to a pre-Fabric OS v10.0.x release.
  • If you have configured any custom rules for the ETH_MGMT_PORT_STATE monitoring system and ALL_SLOTS group, the downgrade to pre-Fabric OS v10.0.x is blocked. Ensure that those rules are deleted before the downgrade.
  • If any custom MAPS rules in a custom policy is present with SFP_HIGH_ALARM_TH or SFP_LOW_ALARM_TH thresholds, the downgrade to pre-Fabric OS v10.0.x is not supported. Ensure that these rules are deleted before the downgrade.
  • The SYSTEM_INTEGRITY_CHECK monitoring system is not supported in pre-Fabric OS v10.0.0 release. These rules will not be monitored after the downgrade.
  • The TLSv1.3 protocol for secure SMTP is not supported in the pre-Fabric OS v10.0.x releases. If you have configured the TLSv1.3 protocol in Fabric OS v10.0.x, the downgrade to the pre-Fabric OS v10.0.x release is blocked.
