Augmenting a Group of Ports

MAPS predefined groups, except for Port groups, are not modifiable. The MAPS port group augmentation feature enables modifications to group membership, including the addition, deletion, or restoration of members within these predefined MAPS logical groups.
In Fabric OS v10.0.x, the MAPS port group augmentation feature is supported for the following port groups:
  • ALL_HOST_PORTS
  • ALL_TARGET_PORTS
Augmentation feature is not supported for the following port groups:
  • ALL_FC_PORTS
  • ALL_ETH_PORTS
  • ALL_QUANRANTINED_PORTS
In pre-Fabric OS v10.0.x, more Port groups were supported for port group augmentation, but from Fabric OS v10.0.x onwards, port group augmentation is obsoleted for the following predefined groups:
  • ALL_E_PORTS
  • ALL_F_PORTS
  • ALL_PORTS
  • NON_E_F_PORTS
  • ALL_D_PORTS
  • ALL_N_PORTS
Use the following commands to add or delete the specific ports from a group:
  • To add ports to the group, enter the logicalGroup --addmember <group_name> -members <member_list> command.
  • To remove ports from the group, enter the logicalGroup --delmember <group_name> -members <member_list> command.

The following example adds a port 3/2 to the ALL_HOST_PORTS group:switch:admin> logicalgroup --addmember ALL_HOST_PORTS -members 3/2

The following example removes port 2/15 from the ALL_TARGET_PORTS group:switch:admin> logicalgroup --delmember ALL_TARGET_PORTS -members 2/15
