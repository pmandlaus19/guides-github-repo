Front-End Ports

The FC Front-End port object type allows you to monitor the FC physical ports. You can use the following monitoring systems to monitor the FC Front-End ports:

  • C3TXTO
  • CRC
  • CURRENT
  • DEV_LATENCY_IMPACT
  • DEV_LOGIN_DIST
  • DEV_NPIV_LOGINS
  • ENCR_BLK
  • ENCR_DISC
  • ENCR_SHRT_FRM
  • ITW
  • PORT_BANDWIDTH
  • MAX_RD_PENDING_IO
  • MAX_WR_PENDING_IO
  • LF
  • LOSS_SIGNAL
  • LOSS_SYNC
  • LR
  • PE
  • PWR_HRS
  • RD_STATUS_TIME_VIOL
  • ROUTING_ERR
  • SFP_TEMP
  • STATE_CHG
  • WR_1stXFER_RDY_VIOL
  • RD_1stDATA_TIME_VIOL
  • RX
  • RXP
  • SFP_STATE
  • TX
  • TXP
  • TEMPERATURE
  • UTIL
  • VOLTAGE
  • WR_STATUS_TIME_VIOL

Starting from Fabric OS v10.0.x, MAPS has been enhanced to dynamically monitor threshold values for SFP parameters directly from vendor-programmed SFP modules. This functionality allows MAPS to read the actual threshold value configured by the vendor for a specific SFP module, rather than relying on static threshold values defined within MAPS rules. This functionality helps to avoid the manual configuration of static SFP thresholds in MAPS rules and the creation of new logical groups for each type of SFP.

On Brocade Gen 7 systems, the existing pre-Fabric OS v10.0.x SFP-specific rules are deprecated and these rules are not associated with any MAPS default policies. If you want to use these predefined rules, ensure that the predefined rules are configured with custom policies.

The following table lists the predefined groups for the FC Front-End ports.

Predefined Groups for the FC Front-End Ports Object Type

Predefined Group Name
Description
ALL_PORTS
  • ALL_PORTS: Includes both FC and Ethernet (ETH) ports.
  • ALL_FC_PORTS: Contains only FC ports.
  • ALL_ETH_PORTS: Contains only ETH ports.

All physical FC and ETH ports in the logical switch. Consider the following points when you switch a port from one type to another:

  • When an FC port is switched to IPS LS, the port is added to the ALL_PORTS and ALL_FC_PORTS groups.
  • When a port is moved out of an LS, it is removed from the ALL_PORTS, ALL_FC_PORTS, or ALL_ETH_PORTS groups depending on the type of port.

When an FC port is converted to an ETH port, it is moved from ALL_FC_PORTS to ALL_ETH_PORTS, while remaining in ALL_PORTS. Conversely, if an ETH port is converted to an FC port, it is moved from ALL_ETH_PORTS to ALL_FC_PORTS.

ALL_FC_PORTS

All physical FC ports in a logical switch for monitoring both online and offline FC port only statistics. Consider the following when you switch a port from one type to another:

  • The FC port is added to the ALL_PORTS and ALL_FC_PORTS groups if it is moved into IPS LS.
  • When the port configuration changes from FC to Ethernet, it is deleted from the ALL_FC_PORTS group and added to the ALL_ETH_PORTS group.
  • Changing the port configuration from Ethernet to FC results in the port being removed from the ALL_ETH_PORTS group and added to the ALL_FC_PORTS group.
ALL_D_PORTS
All D_Ports in the logical switch.
ALL_E_PORTS
All E_Ports and EX_Ports in the logical switch. This group also includes all the ports in E_Port, and EX_Port trunks.
ALL_N_PORTS
All N_Ports used to connect a node to a Fibre Chanel switch.
ALL_F_PORTS
All F_Ports in the logical switch. This group also includes all the ports in the F_Port trunks.
ALL_OTHER_F_PORTS
All F_Ports in the logical switch that is not a host or a target port. FCLAG ports are monitored as a part of the ALL_F_PORTS and ALL_OTHER_F_PORTS groups.
NON_E_F_PORTS
All ports in the logical switch that are not E_Ports, N_Ports, or F_Ports.
ALL_QUARANTINED_PORTS
Ports within a logical switch that are isolated from other ports traffic due to detected congestion.
ALL_ETH_PORTS
All physical Ethernet ports in the switch. You cannot move ETH ports into non-IPS LS. Inthe case of an FC port configured as an ETH port, it is moved from the list of ALL_FC_PORTS to the list of ALL_ETH_PORTS, and the same applies in reverse.
