Extension Health

The Extension Health category enables you to define rules for Extension health, including circuit state changes, circuit state utilization, and packet loss.

The following table lists the parameters in the Extension Health category that are monitored on all Brocade platforms.

Extension Health Category Parameters

Monitoring System

Description

CIR_PKTLOSS

Describes the percentage of the total number of FCIP circuit packets that had to be retransmitted.

CIR_STATE

Describes the state of the FCIP circuit that has changed for one of the following reasons:

  • The circuit has gone offline.
  • The circuit has come online.
  • The circuit is faulty.

CIR_UTIL

Describes the percentage of FCIP circuit utilization.

IP_UTIL

Describes the tunnel IP utilization percentage.

IP_JITTER

Describes the amount of jitter in an IP circuit that is calculated in percentage.

IP_RTT

Describes the IP circuit round-trip latency, which is an absolute value.

JITTER

Describes the amount of jitter in an FCIP circuit that is calculated in percentage.

PKTLOSS

Describes the percentage of the total number of packets that must be re-transmitted in each QoS level.

RTT

Describes the FCIP circuit round-trip latency, which is an absolute value.

IP_EXTN_FLOW

Describes the number of LAN IP Extension flows (TCP connections).

STATE_CHG

Describes the count of FCIP tunnel and FCIP QoS state changes that applies to the tunnel group only.

UTIL

Describes the percentage of FCIP utilization that applies to both the tunnel and the tunnel QoS groups.

IP_PKTLOSS

Describes the percentage of the total number of IP circuit packets that had to be retransmitted.

If the default policy does not meet your requirements, you can clone an existing default policy and create a custom rule. When you create a custom rule, you must account for the constraints that are associated with each parameter of that rule. The following information is provided to help you effectively manage MAPS features, with each component designed for a specific purpose.
  • Monitoring Systems Matrix
  • States Severity
  • MAPS Default Rules
  • MAPS Default Groups
For more information, refer to the Brocade Fabric OS MAPS Rules Reference Manual.

Rule Data

The following example shows one of the default rules to monitor Extension Health. This rule triggers the configured actions when the percentage of the total number of IP circuit packets to be retransmitted is greater than 5.

RuleName: defALL_CIRCUITSCIR_PKTLOSS_PER_5
Condition: ALL_CIRCUITS(CIR_PKTLOSS/MIN>0.5)
Actions: RASLOG,SNMP,EMAIL
Associated Policies: dflt_conservative_policy












































RASLog Example
