MAPS Group Types

MAPS supports different group types that are used in the dashboard category for monitoring. A set of similar objects that combine to form a single entity is referred to as a group or logical group. For example, you can combine all the small form-factor pluggable (SFP) transceivers for the ALL_PORTS group. Then you create specific rules for monitoring this group which facilitates the effective monitoring of the SFP ports.

The MAPS object view describes the types of MAPS groups and elements that can be monitored using MAPS. For example, you can use the switchshow command to view the switch ports, connections, and status of all ports without MAPS.
