MA0013

ERROR LOADING MAI SESSION DEFINITIONS, MODEL aaaaaaaa

Reason:

An error has occurred loading the MAI session definition list. The MAI session list 'aaaaaaaa' could not be accessed.

System Action:

A message indicating the cause of the error is logged. MAI-FS functions may be restricted.

User Action:

Report the problem to your systems administrator. Ensure that your MAI user attributes are correctly defined.
