MA7010

ERROR ON CALL TO NSI INTERFACE. FNMNSI RC/FB=P1/P2 MSG=P3

Reason:

An error occurred in the module which sends MAI event data to the FNMNSI module which is part of the NetView(TM) Synergy Interface.

P1 is the return code set by the FNMNSI module, P2 is the reason code set by the FNMNSI module. P3 is an explanatory error message set by the MAI:NSI interface.

System Action:

none.

User Action:

Look up FNMNSI RC/FB in the NPM Installation and Customisation guide.
