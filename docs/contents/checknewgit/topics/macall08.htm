MACALL08

Unable to start session for p1

Reason:

An attempt to start the MAI session definition for logon script generation has failed.

System Action:

The request is rejected. The MACALL07 message containing the specific error details is written to the log.

User Action:

Review the MACALL07 message in the log to determine the cause of the error. Check that P1 is active, and that the corresponding application ID is defined and active on this system.
