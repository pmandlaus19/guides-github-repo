MACALL07

P1

Reason:

This message is written to the log after an MACALL08 message indicating that a session could not be started. The message text indicates the nature of the error in the first line of output from an MAISESS START command. Possible causes include the following:

INACT
Indicates that the application ID is known to VTAM but inactive.
VTAM UNKNOWN
Indicates that the application ID is not known to VTAM.

System Action:

None.

User Action:

Use the message text to determine the reason for the error.
