MA3019

Database Error - User=P1 Seq=P2 Error=P3

Reason:

An error occurred when trying to access the MAI Stored Definitions database, which indicates that the database is corrupted. The fields displayed are:

P1 is the user ID for whom records were being accessed

P2 is the record sequence number that was read

P3 is a description of the problem

System Action:

None.

User Action:

You must delete the corrupted record from the file.

MAI Session Definitions are stored on the SOLVE:Access Data Base (ACDB). Records have a 36-byte key with the following format:

1 - 4 (4) is an identifier, x'00050001'

5 - 12 (8) is the user ID (P1)

13 - 14 (2) is a sequence number, in binary (P2)

15 - 36 (22) is unused (binary zeroes)

To delete this record, you can use $UTXFILE as follows:

  1. EXEC $UTXFILE (in OCS or Command Entry). The File Utility : BROWSE panel is displayed.
  2. Specify the following and then press Enter:
    • File ID = ACDB
    • File Mode = U (Unformatted)
    The first record is displayed.
  3. Press F6 (Char/Hex) to switch to hexadecimal display format.
    Note: The $UTXFILE utility supports character and hexadecimal display formats, and the F6 (Char/Hex) key is used to switch between formats. MAI Session Definition records contain hexadecimal data in the key and data parts of each record. You must use the hexadecimal display format when moving through the file or modifying records.
  4. In hexadecimal display format, overtype the key field as follows, and then press Enter:00050001uuuuuuuuuuuuuuuussss where:uuuuuuuuuuuuuuuu is the user ID in hexadecimal (see below)ssss is the sequence number in hexadecimalThe record with the requested key, or next higher, is displayed.
    Note: Use F6 to switch back to character display to check the user ID in the key. You must press F6 again to switch back to hexadecimal display before you continue.
  5. If the correct key is not displayed, repeat steps 1 to 4 until the correct record is displayed.
  6. Press F12 (Upd/Del) and then press F11 (Delete) to delete the record.
  7. Press F3 (End) to exit.
