Iframe Edge-Case Test (EDS publish)

Every iframe variant that iframesToVideoLinks can hit. Each DITA object with type="text/html" data="URL" becomes an <iframe src="URL"> in the EDS HTML, which the publisher then rewrites. Legend: [GOOD] = should become a clean watch link; [WRONG] = currently degrades to a bare raw-URL link (non-video); [EDGE] = DOM/parse edge case.

A. Video iframes — [GOOD] should become a clean watch link

A1. YouTube standard embed: https://www.youtube.com/watch?v=GSj_wv3sgK8

A2. YouTube embed WITH query params (must keep or normalize to the watch URL, not corrupt): https://www.youtube.com/watch?v=GSj_wv3sgK8?start=30&rel=0&controls=1

A3. youtube-nocookie embed (privacy domain — must still be detected as video): https://www.youtube.com/watch?v=GSj_wv3sgK8

A4. Vimeo player embed: https://vimeo.com/76979871

A5. Vimeo embed WITH hash + query (private-video hash must not break the link): https://vimeo.com/76979871?h=8272103f6e&autoplay=1
